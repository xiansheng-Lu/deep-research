## 1. 设计基调与品牌定位

| 维度 | 决策 |
|---|---|
| 整体气质 | 工业中性型（参考 Linear、Notion、Stripe Dashboard） |
| 主题模式 | 浅色为主 + 深色可选 + 系统跟随 |
| 信息密度 | 中密度（面向多角色研究员，平衡型） |
| 颜色策略 | 低饱和深靛蓝主色 + 中性灰阶 + 状态色 |
| 字体策略 | 中英混排双字体（中文思源黑体 + 英文 Inter，代码 JetBrains Mono） |

**品牌锚点**：严谨、可信、可追溯。不张扬、不消费产品感；学术-工业中性气质。

### 2.5 阴影系统（极浅阴影，仅用于浮层）

| Token | 用途 |
|---|---|
| `--shadow-popover` | `0 2px 8px rgba(15, 17, 23, 0.06), 0 1px 2px rgba(15, 17, 23, 0.04)` |
| `--shadow-dropdown` | `0 4px 12px rgba(15, 17, 23, 0.08), 0 2px 4px rgba(15, 17, 23, 0.04)` |
| `--shadow-modal` | `0 12px 32px rgba(15, 17, 23, 0.12), 0 4px 8px rgba(15, 17, 23, 0.06)` |
| `--shadow-drawer` | `-8px 0 24px rgba(15, 17, 23, 0.08)`（右侧抽屉） |

**关键约束**：研究报告产品**不使用阴影区分卡片层级**——卡片层级由 1px 边框（`--neutral-200`）和密度差异承担。阴影仅用于脱离页面的浮层元素。

### 2.6 动效系统

| Token | 时长 | 缓动 | 用途 |
|---|---|---|---|
| `--motion-fast` | 150ms | `ease-out` | 微交互（按钮按下、勾选） |
| `--motion-base` | 220ms | `cubic-bezier(0.4, 0, 0.2, 1)` | 默认过渡 |
| `--motion-slow` | 300ms | `cubic-bezier(0.4, 0, 0.2, 1)` | 阶段切换、抽屉展开 |
| `--motion-slower` | 450ms | `cubic-bezier(0.16, 1, 0.3, 1)` | 模态、浮层入场 |

**关键约束**：所有动效必须**尊重 `prefers-reduced-motion: reduce`**——系统设置开启减少动效时，所有过渡时长缩为 0，仅保留必要的状态变化。

## 4. 核心页面布局

### 4.1 首页

**布局**：三列布局

- 左列：欢迎语 + 快捷新建入口 + 最近活动
- 中列：进行中研究（实时状态卡片）
- 右列：推荐模板 + 系统公告/小贴士

**空状态**（DS-Q30）：示例报告 + 主按钮"开始你的第一次研究"

### 4.2 发起研究页（5 步向导）

**模式**：分页向导（DS-Q11），可保存草稿

```
┌─────────────────────────────────────────────────────┐
│  发起研究                                    [关闭]   │
├─────────────────────────────────────────────────────┤
│  ● 选择模板 ─── ○ 设置参数 ─── ○ 描述问题 ─── ...    │
├─────────────────────────────────────────────────────┤
│                                                     │
│   步骤内容区（每步不超过 3 个核心字段）              │
│                                                     │
├─────────────────────────────────────────────────────┤
│  [保存草稿]                            [上一步] [下一步] │
└─────────────────────────────────────────────────────┘
```

5 步内容：

| 步骤 | 字段 |
|---|---|
| 1. 选择模板 | 模板卡片网格（顶部高频+推荐） |
| 2. 设置参数 | 档位选择、深度上限、约束条件 |
| 3. 描述问题 | 多行文本框（核心研究问题）+ 关键词标签 |
| 4. 预读与确认 | 系统对问题的解读 + 预期研究范围 + 成本预估 |
| 5. 启动 | 启动按钮 + 立即跳转到指挥舱 |

**6 阶段时间线**（DS-Q23）：左侧垂直时间线，每个阶段一个节点 + 状态点（完成/进行中/等待/失败）。节点可点击展开看子任务。

**阶段切换动效**（DS-Q24）：进度条线性填充 + 节点渐变着色（200-300ms）。阶段图标不使用旋转动画。

**证据流卡片**（DS-Q25）：紧凑列表行 + hover 展开元数据（域名/发布时间/类型/可信分级）。

**成本展示**（DS-Q15）：右下角固定卡片，含进度条；接近档位上限时弹出警告。

## 5. 关键交互模式

### 5.1 看板刷新节奏

指挥舱的实时刷新必须**用户感知但不打扰**：

| 事件 | 刷新方式 |
|---|---|
| 新增证据 | 列表行渐入（150ms） |
| 子问题完成 | 节点渐变着色 + ✓ 图标（300ms） |
| 阶段切换 | 进度条线性填充 + 当前阶段名淡入（300ms） |
| 报告片段生成 | 右栏"实时输出"流式追加（光标闪烁） |
| token 告警 | 警告卡片从右下角弹出（400ms），可关闭 |
| 冲突/分歧检出 | 证据流对应行加 `--danger-500` 边框 + 角标 |

**WebSocket / SSE**：阶段状态、子问题完成、token 计数必须实时推送（≤ 3 秒延迟）；证据全文与摘要按需懒加载。

### 5.2 用户介入操作

智能体协作规格 §10.5 定义的介入操作通过以下入口触发：

| 操作 | 入口 | 形态 |
|---|---|---|
| 暂停 | 顶栏"暂停"按钮（指挥舱） | 模态确认 |
| 追问方向 | 阶段节点旁"+ 追问"按钮 / 命令面板 | 内联输入 |
| 剔除证据 | 证据流卡片上 ✕ 按钮（hover 显示） | 单击直接剔除 + Toast 反馈 |
| 打回重审 | 阶段节点旁"↺ 打回"按钮（M4 起） | 模态输入原因 |
| 标存疑 | 报告论断角标右侧"⚠ 存疑"按钮（M4 起） | 单击标注 + 触发补查 |

**权限边界**：用户不能修改 prompt，只能触发受控的"重跑/追问/剔除"操作。所有介入操作记录到审计日志。

### 5.3 冲突/分歧的视觉处理

研究产品在"冲突处理"上的视觉必须诚实：

- **可调和冲突**：收敛后不显式提示（避免噪音）
- **不可调和分歧**：报告内联警告块（`--danger-500` 色，感叹号图标）+ 末尾"研究局限"区块汇总
- **信源等级差异**：相同论断的不同信源，按可信分级排序（颜色编码），不强求共识
- **未决问题**：报告末尾区块列出所有未决问题（含原因：是数据缺失、源冲突还是模型无法判断）

### 5.4 报告角标展开行为

- **悬停**：鼠标悬停角标 200ms，弹出 popover（标题 + 来源域名 + 1 行原文）
- **单击**：固定展开溯源（右侧抽屉）
- **键盘**：Tab 聚焦角标，方向键切换溯源条目，Enter 打开抽屉

### 5.5 命令面板（Cmd+K，M3 起）

**触发**：全局 Cmd/Ctrl + K

**行为**：

- 顶部搜索框 + 命令分类列表
- 支持：新建研究、跳转到项目、跳转到模板、查看历史、账户设置
- 模糊匹配 + 键盘导航（上下方向键 + Enter）

### 5.6 加载与空状态

| 状态 | 设计 |
|---|---|
| 加载中（≤3s） | 内容区骨架屏（不闪烁） |
| 加载中（>3s） | 进度提示文案（"正在执行 XX 阶段..."） |
| 错误 | 顶部红色横幅 + 重试按钮 |
| 空状态 | 示例报告引导 + 主按钮（DS-Q30） |
| 无网络 | 全屏插画 + 重连按钮 |

### 5.7 表单交互

- **输入框**：聚焦时边框转 `--brand-500`，错误时转 `--danger-500`，错误文案显示在输入框下方
- **按钮**：主按钮（`--brand-500`）、次按钮（中性边框）、危险按钮（`--danger-500`）
- **下拉/选择**：使用浮层（`--shadow-dropdown`），含搜索框（模板选择器必备）

## 7. 可访问性

### 7.1 WCAG 2.1 AA 关键要求

| 维度 | 要求 |
|---|---|
| 文本对比度 | 正文 ≥ 4.5:1，大字 ≥ 3:1 |
| 键盘可访问 | 所有交互元素 Tab 可达，Enter/Space 触发 |
| 焦点可见 | 自定义焦点环（`--brand-500` 外发光，2px） |
| 屏幕阅读器 | 所有角标、冲突块、阶段节点必须有 aria-label |
| 语义结构 | 正确使用 `header/main/nav/aside/article` |
| 表单标签 | 所有输入有可见标签 + aria-describedby 错误说明 |

### 7.2 动效与认知负荷

- 尊重 `prefers-reduced-motion`
- 长时间看板刷新不应自动滚屏（用户掌控）
- 实时输出流不应闪烁（光标最多 1 次/秒）
