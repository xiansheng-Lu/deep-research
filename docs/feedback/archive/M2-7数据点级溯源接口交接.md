## 3. 终稿数据行为（解释异常渲染）

1. **marker 仅被引证据占号**：按材料池顺序（跨子问题、可信度→相关性）为**被引用到的**证据编号，未被任何 block 引用的证据不占号、不在 citations 端点返回；真链信源条数 ≤ 证据总数。与 fixture「全量占号」不同（demo 12 条恰好全被引，输出碰巧一致）。
2. **snippet 两级粒度**：LLM 提供 quote 且在 trafilatura 正文中命中 → 取原句窗口（约 120 字，最细粒度）；未提供/正文缺失/不命中 → 回证据检索摘要。两种情况引用都保留，回溯不损。
3. **100% 绑定硬指标**：含数字/百分比/金额/年份等数据点的 conclusion 无引用时，后端做一次整份自修复；仍无引用的数字块直接从终稿剔除（不冒充事实）；无数字的无来源结论强制降级 `inferred` 保留。内部审计在 `content_json.citation_audit`（不进响应）。
4. **dispute 块后端确定性注入**：待裁决冲突与 both/reject 保留分歧各一块，强制挂双方/存活方证据与 `conflict_id`；双方证据均被用户剔除时该冲突不出块（仍可在分歧列表端点查看）。
5. **终稿 status=final**：取消运行保留的部分稿仍为 draft（旧 content_json 形态、blocks/outline 空、无引文）。

## 9. 联调问题（2026-09-14 前端真链回归提出，责任方：后端）

### P1-1：兜底概述块绕过数字绑定审计，零引用「推断」结论可携带年份/数量词

**现象（必现路径，概率触发）**
真链 run `01M2G1N5YBTV2G21MFGKA2YPST`（2026-09-14 13:29 UTC succeeded，standard，问题含「2024年…多少万辆…百分之多少」）终稿 block-01 为：

```json
{"id":"block-01","type":"conclusion","claim_id":"claim-01","confidence":"inferred",
 "text":"围绕「2024年全球新能源汽车销量是多少万辆？同比增长率约为百分之多少？渗透率达到多少？不同机构口径有何分歧？」开展的多源核验已形成以下结构化报告。",
```

浏览器 getComputedStyle 取证：该块以 conclusion 论断样式 + 灰色「推断」徽标（rgb(92,100,120)/rgb(238,241,245)）置顶渲染，块内 0 角标，文本含年份「2024」与数量词「万辆」。与本交接 §3.3「100% 绑定硬指标」及 §5「inferred 块不含无来源数字」验收口径冲突。

**代码级根因（时序机制）**
`backend/app/reporting/blocks.py` 存在两条进入终稿的路径，数字审计只覆盖第一条：

1. §5.5 审计循环（`assemble_report` L333-355）：无引用 conclusion 命中 `has_numeric_assertion`（L92-99 正则首分支即裸 `\d`，年份必然命中）即剔除——本 run 该轮计数 `dropped_numeric_blocks=1`，LLM 唯一的数字结论在一次自修复后仍被剔除；
2. 剔除后终稿零 conclusion，L377-380 直接 `ordered.insert(0, _fallback_overview_block(question))`；`_fallback_overview_block`（L302-306）把**研究问题原文**嵌进结论（`围绕「{question}」开展…`），产出的是普通 dict 而非 DraftBlock，**不经 §5.5 审计、不占 dropped 计数**，携带数字时原样进终稿并在 L412-461 被分到 claim_id=claim-01、confidence=inferred、citations=[]。

DB 取证（`reports.content_json.citation_audit`，该 run）：`reporter_degraded=false、dropped_numeric_blocks=1、forced_inferred_blocks=1、claim_blocks=1、numeric_claim_binding_rate=1.0`——恒等式自检报 1.0 的同一份终稿里实际存在无引用数字 conclusion，自相矛盾。

**触发条件（非孤例）**：LLM 产出的全部 conclusion 被数字审计剔除（或机械降级无 claim）且研究问题含数字/年份/数量词时必现；数字问题正是 A2 抽验建议的问题形态，5 run 样本中第 1 个即命中。
