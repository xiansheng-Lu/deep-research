## 2. 值语义变化（字段名不变，值变真实）

| 字段 | 修复前（真链） | 修复后（M2-6） |
| --- | --- | --- |
| `source_type` | 博查 WEB 命中几乎全标 `news`（政府公告/论坛帖也是 news） | 按域名规则真实产出 `official_doc / news / community / search`（`internal` 本包不产出，属 M5） |
| `source_level` | 仅 6 个英文后缀，中国权威源大量漏判为 tertiary | 扩充政府/国际组织/学术/主流媒体/社区规则表，primary/secondary/tertiary 真实分布 |
| `credibility` | relevance 真链恒 0 → 全部降两档，**政府站也评 C** | 权威定基准、相关性至多降一档、**primary 地板 B**：stats.gov.cn 等高相关权威源为 A |
| `relevance_score` | 恒 0.0（fan-out 不写、博查无分） | 每条按子问题词面相关性打分（0~1，三位小数），与 Tavily provider 分 0.5/0.5 融合 |
| `published_at` | Provider 不返即永久 null | Provider 优先；缺失时小预算抓页面 HTML 元数据补采（默认每子问题≤3 条、5s、失败静默） |

规则判定优先级（供解释 SourceBadge 异常归类）：PRIMARY_OFFICIAL（gov.cn/gov/who.int 等）→ PRIMARY_ACADEMIC（edu/ac/arxiv/nature/ieee 等）→ SECONDARY_NEWS（新华网/人民网/央视/财新/路透/BBC 等）→ TERTIARY_COMMUNITY（知乎/微博/CSDN/Stack Overflow/github 等）→ 独立 `news` 标签弱兜底 → 默认 tertiary/search。`fake-news.example.com` 这类连写/拼接域名**不会**误判为媒体。
